================================================================================
🛠️ TROUBLESHOOTING
================================================================================

"Port already in use"?
   → Change port in app.py (last line), change 5000 to 8000
   → Run again

"Module not found" error?
   → pip install -r requirements.txt
   → Try again

"Page won't load"?
   → Make sure you're on http://localhost:5000/
   → Not https, not 127.0.0.1:5000
   → Refresh the page (Ctrl+R or F5)

"Login not working"?
   → Check caps lock (credentials are case-sensitive)
   → Username: admin (lowercase)
   → Password: admin123 (numbers, not letters)

"Need more help"?
   → Open README.md → Troubleshooting section
   → Press F12 in browser → Console tab → Look for red errors
   → Check INDEX.md for navigation
